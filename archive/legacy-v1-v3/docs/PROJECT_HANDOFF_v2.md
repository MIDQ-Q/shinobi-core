### Что уже сделано (работает):
- Чакра-режим (L): вода, стены, спринт, прыжки
- Паркур: 9 действий (slide, wall run, edge grab, charged jump, roll, dodge, crawl)
- Тай-дзюцу: комбо 4 удара, удар ногой, стили Standard/Strong Fist, анти-чит
- 20+ техник по 5 стихиям + медицинские + тай-дзюцу
- Расенган: зарядка в руке, рывок ЛКМ, синий+белый визуал
- Клановая система: 6 кланов JSON, costMultiplier, fatigueMultiplier, statBonuses
- Камера: over-the-shoulder, плавная, Naruto run анимация
- Визуал техник: текстура лавы, 6 квадов для объёма
- HUD в стиле Naruto, меню прокачки K (свиток)
- JutsuLogger: отдельный лог для отладки техник

3. **Гендзюцу** — фреймворк, резист, снятие, визуал
4. **Тай-дзюцу v2** — блокирование, парирование, Gentle Fist
5. **Сюрикен-дзюцу** — метание, предметы
6. **Кен-дзюцу** — катаны, анимации
7. **Визуал** — анимация каста (печати), свечение рук
8. **Стена v2** — полноценная (ноги на стене, мир переворачивается)
9. **Баланс прыжков** — сейчас перебор
10. **Перевод + звуки** — lang, ванильные звуки
11. **Клоны + контент** — ПОСЛЕДНЯЯ ОЧЕРЕДЬ

### Идеи из других модов (пользователь хочет):

- Iron's Spells → анимация каста (руки складываются в печати)
- Epic Fight / Better Combat → интеграция боевой системы

- ProjectileUtil.getEntityHitResult — другая сигнатура в 1.20.1. Использовать Box.raycast().
