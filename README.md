## 🎯 Первый запуск

1. При первом входе в мир выберите клан (можно сменить позже командой)
2. Откройте древо навыков клавишей `K`
3. Используйте `Shift` для активации чакра-режима
4. Изучите команды: `/shinobicore help`

## ⌨️ Команды

### Основные
- `/shinobicore` — основная команда мода
- `/shinobicore_test systems` — тест всех систем (только для операторов)
- `/shinobicore_test balance` — показать бонусы кланов
- `/shinobicore_test spawn <rank>` — заспавнить врага
- `/shinobicore_test reputation <player>` — показать репутацию
- `/clan info` — информация о текущем клане
- `/clan leave` — покинуть клан

### Отладочные (только для операторов)
- `/testall` — полный тест всех систем
- `/give @p shinobicore:katana_diamond` — получить алмазную катану

## 🔄 Смена клана

Изначально клан выбирается при первом входе в мир. Для смены:

```
/clan leave
```

После этого при следующем входе появится выбор нового клана.

**Внимание:** При смене клана вы теряете доступ к клановым техникам предыдущего клана (кроме универсальных).
