# 🏯 Генерация мира ShinobiCore

## Обзор

Мод ShinobiCore реализует **гибридную систему генерации мира** в стиле средневековой Японии, которая добавляет:
- Природные элементы (сакуры, бамбуковые рощи, пруды с кои)
- Декоративные структуры (каменные фонари, дзен-сады, рисовые поля)
- Жилые постройки (японские дома, деревни кланов)
- Специализированные здания (доджо, тренировочные полигоны)

## Типы генерации при создании мира

При создании нового мира игроки могут выбрать один из следующих типов генерации:
1. **Стандартный** - обычная генерация Minecraft с добавлением японских элементов
2. **Лесной** - увеличенная частота лесных биомов с сакурами и бамбуком
3. **Горный** - огромные японские горы с храмами и водопадами
4. **Равнинный** - обширные равнины с рисовыми полями и деревнями

## Природные элементы

### Сакуры (`sakura_tree`)
- **Частота**: Высокая в лесных биомах
- **Описание**: Вишнёвые деревья с розовыми листьями
- **Биомы**: Леса, цветочные леса

### Бамбуковые рощи (`bamboo`)
- **Частота**: Средняя (1 раз на 4 чанка)
- **Описание**: Кластеры высокого бамбука (4-11 блоков)
- **Биомы**: Леса, джунгли, бамбуковые леса

### Пруды с кои (`koi_pond`)
- **Частота**: Редкая (1 раз на 12 чанков)
- **Описание**: Небольшие пруды с кувшинками и гравием на дне
- **Биомы**: Равнины, луга, биомы у воды

### Рисовые поля (`rice_field`)
- **Частота**: Средняя (1 раз на 6 чанков)
- **Описание**: Террасы с водой и молодым рисом, огороженные забором
- **Биомы**: Равнины

### Дзен-сады (`zen_garden`)
- **Частота**: Редкая (1 раз на 10 чанков)
- **Описание**: Площадки с гравием, мхом и декоративными камнями
- **Биомы**: Все биомы

### Каменные фонари (`stone_lantern`)
- **Частота**: Средняя (1 раз на 8 чанков)
- **Описание**: Декоративные фонари вдоль дорог и у структур
- **Биомы**: Все биомы

## Структуры

### Японские дома (`japanese_house`)
- **Частота**: Средняя (1 раз на 5 чанков)
- **Описание**: Традиционные дома с соломенными крышами и сёдзи
- **Биомы**: Все биомы

### Ворота Тории (`torii_gate`)
- **Частота**: Редкая (1 раз на 15 чанков)
- **Описание**: Священные ворота синтоистских храмов
- **Биомы**: Леса, горы

### Японские мосты (`japanese_bridge`)
- **Частота**: Средняя (1 раз на 8 чанков)
- **Описание**: Арочные мосты через реки и овраги
- **Биомы**: Реки, овраги

### Деревни шиноби (`hidden_village`)
- **Частота**: Очень редкая (1 раз на 40 чанков)
- **Описание**: Большие деревни с несколькими кланами
- **Биомы**: Все биомы

### Тренировочные полигоны (`training_ground`)
- **Частота**: Средняя (1 раз на 10 чанков)
- **Описание**: Полигоны с манекенами и мишенями
- **Биомы**: Все биомы

### Доджо кланов (`clan_dojo`)
- **Частота**: Редкая (1 раз на 20 чанков)
- **Описание**: Специализированные залы для тренировок клана
- **Биомы**: Все биомы

## Деревни кланов

Каждая деревня клана генерируется с:
- **5-8 домов** расположенных по кругу
- **2 уникальные структуры** зависящие от клана:
  - **Uchiha**: Алтарь огня с незерраком
  - **Hyuga**: Большое татами доджо
  - **Uzumaki**: Барьерная печать с колоннами
  - **Senju**: Роща сакур
  - **Nara**: Колодец теней из глубинного сланца
  - **Aburame**: Улей из медовых блоков
  - **Inuzuka**: Вольер с заборами
  - **Akimichi**: Закусочная с столами
  - **Hatake**: Мемориал с каменным монументом

Клан определяется детерминировано на основе координат деревни, что гарантирует одинаковый клан в одном и том же месте при каждой генерации.

## Конфигурация

Все параметры генерации можно настроить в файле `config/shinobicore/worldgen.json`:

```json
{
  "sakura_tree_chance": 0.3,
  "bamboo_chance": 0.25,
  "koi_pond_chance": 0.08,
  "rice_field_chance": 0.15,
  "zen_garden_chance": 0.1,
  "stone_lantern_chance": 0.12,
  "japanese_house_chance": 0.2,
  "torii_gate_chance": 0.06,
  "japanese_bridge_chance": 0.12,
  "hidden_village_chance": 0.025,
  "training_ground_chance": 0.1,
  "clan_dojo_chance": 0.05
}
```

## Технические детали

### Регистрация фич
Все функции генерации регистрируются через `ShinobiWorldGenerator`:
- `FEATURES` - registry самих фич
- `PLACED_FEATURES` - registry размещений с условиями
- `BIOME_MODIFIERS` - модификаторы для добавления в биомы

### Классы фич
- `SakuraTreeFeature` - генерация сакур
- `BambooFeature` - генерация бамбука
- `StoneLanternFeature` - генерация фонарей
- `KoiPondFeature` - генерация прудов
- `RiceFieldFeature` - генерация рисовых полей
- `ZenGardenFeature` - генерация дзен-садов

### Классы структур
- `ClanVillageGenerator` - генерация деревень кланов
- `StructureBuilder` - вспомогательные методы для построения
- `HouseStructure` - базовый дом
- `DojoStructure` - доджо
- `ToriiStructure` - ворота тории
- `OnsenStructure` - горячий источник

## Отладка

Для отладки генерации используйте команды:
- `/locate structure shinobicore:hidden_village` - найти ближайшую деревню
- `/locate structure shinobicore:japanese_house` - найти ближайший дом
- `/tp @p ~ ~100 ~` - подняться для обзора местности

Логи генерации пишутся в файл `logs/latest.log` с префиксом `[ShinobiCore/WorldGen]`.
