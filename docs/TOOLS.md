# Инструментарий ShinobiCore (ToolsPack 1.1.2)

Единая точка входа для создания контента БЕЗ правки Java-кода.

## 1. Studio (браузерный редактор)
Запуск:
    cd E:\Games\mod
    powershell -ExecutionPolicy Bypass -File tools\studio\serve.ps1
    # браузер: http://localhost:8420/

Разделы (первые четыре — из базовой студии):
- Техники / Дерево / Кланы / Локализация / Звуки / Рецепты / Проверка / Словарь
- 🎆 FX Lab — симуляция визуала техники (круг каста, полёт, луч, зона, попадание);
  правка visual-блока (цвет/частицы/масштаб/свечение/модель) с мгновенным превью;
  кнопки «на всю стихию» и «яркий пресет всем».
- 🧊 Воксели — 3D-превью моделей снарядов, генераторы (сфера/звезда/диск/клинок/
  кольцо), правка анимации (spin/pulse/bob) и ауры (particle/particleColor/rate),
  проверка «все ли ссылки из техник обеспечены моделями».
- ⚙ Генераторы — пакетная генерация техник (стихия×форма×ранг с балансом),
  кривые прокачки, достройка дерева навыков под непокрытые техники,
  массовое применение визуала.
- 📐 Форматы — документы и шаблоны будущих паков (предметы, биомы, структуры,
  NPC, квесты, диалоги).

После сохранения из Studio в игре выполнить `/reload` (данные) — техники,
дерево, кланы перечитаются без перезапуска.

## 2. Визуал техник в игре
Каждая техника теперь описывает визуал блоком `visual` в своём JSON:
    "visual": { "particle": "flame", "trail": "flame", "color": "#FF7A1A",
                "voxelModel": "fireball", "scale": 1.0, "glow": true }
Движок (FxPalette.java + Fx.java) применяет его автоматически:
- цвет переопределяет палитру стихии;
- particle/trail — короткие имена пресетов (flame, splash, cloud, electric_spark,
  end_rod, dust, ...) или полные id "minecraft:xxx";
- scale — размер эффектов и пыли (0.4..3);
- glow — дополнительный светящийся слой END_ROD;
- voxelModel — воксельная модель снаряда/ручного конструкта
  (assets/shinobicore/voxels/<имя>.json).

Предпросмотр без каста:
    /shinobicore fx fire            — все эффекты огня рядом с игроком (20 сек)
    /shinobicore fx lightning beam  — один эффект
    /shinobicore fx none zone 2.0   — с масштабом
    /shinobicore fx none stop       — остановить

## 3. Типовой рабочий процесс «новая техника»
1. Studio → Генераторы → Пакет техник: стихия, форма, ранг → Предпросмотр → Сгенерировать.
2. Studio → Техники: открыть созданную, довести название/описание/эффекты.
3. Studio → FX Lab: подобрать цвет/частицы/свечение (превью сразу).
4. Studio → Воксели: если projectile/handheld — сгенерировать или выбрать модель.
5. Сохранить (Ctrl+S) → в игре `/reload` → `/shinobicore jutsu cast <id>`.
6. Studio → Дерево → «Достройка дерева»: добавить узел, если техника в древе.

Java-код трогать не нужно. Код потребуется только для НОВОЙ механики
(новый EffectSubType/FormType/property) — и тогда «Словарь движка» в Studio
сам покажет редактору новые возможности после обновления страницы.

## 4. Форматы будущих паков
docs/formats/*.md — согласованные форматы: items (Спринт 2), biomes (18),
structures (19/21), npcs (20), quests (25), dialogs (20/25).
Шаблоны: data/shinobicore/_templates/*.json (видны и правятся в Studio → Форматы).
Когда спринт доходит до реализации, система строится УЖЕ под согласованный
формат — генераторы и валидация в Studio готовятся заранее.

## 5. Что где лежит
    tools\studio\serve.ps1   — HTTP-хост студии (loopback, белый список записи)
    tools\studio\app.js      — базовые редакторы
    tools\studio\ext.js      — расширение (FX Lab/Воксели/Генераторы/Форматы)
    assets\shinobicore\voxels\*.json      — воксельные модели
    data\shinobicore\jutsu\*.json         — техники (visual-блок внутри)
    src\...\jutsu\executor\FxPalette.java — палитры стихий (зеркало в ext.js: FX_PAL)
    src\...\jutsu\executor\Fx.java        — эффекты (круг каста, луч, зона, вспышки)
    src\...\command\FxPreviewCommand.java — /shinobicore fx
