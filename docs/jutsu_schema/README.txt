Отладочные техники ShinobiCore — СПРАВОЧНИК СХЕМЫ (не загружается игрой)
=======================================================================

Файлы в этом каталоге ВЫНЕСЕНЫ из src/main/resources, поэтому игра их не
видит и TreeAutoGen не создаёт по ним узлов дерева. Здесь они лежат как
живая документация формата jutsu JSON для возможностей движка, которые
не используются в основном контент-паке.

  test_act_on_death.json      активация "on_death" (Идзанаги: переписывает
                              летальный удар). Единственный пример этого типа.
  test_prop_orbiting.json     свойство "orbiting" — объект вращается вокруг
                              кастера. В контент-паке не применяется.
  test_world_transform.json   эффект world:transform_block с параметрами
                              from / to — замена блоков в области.

Полный перечень возможностей движка и их параметров выдаёт:
    powershell -ExecutionPolicy Bypass -File tools\check_jutsu.ps1 -Capabilities
