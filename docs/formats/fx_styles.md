# Каталог стилей и примитивов визуала (ToolsPack 2, 1.1.3)

Стили задаются в `visual`-блоке техники и применяются движком Fx v3
автоматически. Пустое/неизвестное значение = `default`. Подбор с живым
превью — в Studio → 🎆 FX Lab; просмотр в игре — `/shinobicore fx <стихия> <вид> <масштаб> <стиль>`.

## Пример полного visual-блока

```json
"visual": {
  "particle": "flame",
  "trail": "flame",
  "color": "#FF7A1A",
  "voxelModel": "fireball",
  "scale": 1.0,
  "glow": true,
  "trailStyle": "helix",
  "impactStyle": "nova",
  "castStyle": "runes",
  "zoneStyle": "vortex",
  "beamStyle": "lightning"
}
```

## trailStyle — трейл снарядов, рывков, орбит

| стиль | вид | когда хорош |
|---|---|---|
| default | ядро (dust) + стихия + ореол + искры | универсальный |
| ribbon | две синусоидальные ленты вокруг оси движения | вода/ветер, «текучие» снаряды |
| helix | двойная спираль ДНК вокруг оси | Расенган-класс, медицинское, барьерное |
| smoke | дымный шлейф с углями | земля, дымовые бомбы, тяжёлые снаряды |
| sparks | разлетающиеся искры без ядра | метательное, кунаи с печатью |
| lightning | рваные зигзаги разрядов | молния, запрещённые техники |

Для ribbon/helix нужно направление полёта — снаряды его передают;
у орбитальных сфер (OrbitingSystem) эти стили откатываются к default.

## impactStyle — вспышка попадания/взрыва

| стиль | вид | когда хорош |
|---|---|---|
| default | ядро + кольцо + брызги + дым | универсальный |
| nova | default + столп света + широкое второе кольцо | финишеры, S-ранг |
| shockwave | плотное плоское кольцо, быстро летящее наружу | взрывные печати, земля |
| implosion | частицы летят ИЗ окружения В точку + сжатие | печать, гравитация, ян/инь |

## castStyle — круг каста (печати/зарядка/каналирование)

| стиль | вид |
|---|---|
| default | два встречных кольца + падающие внутрь искры |
| runes | неподвижные кольца + 4 вращающихся «глифа» |
| pillars | 6 светящихся столбов по кругу + базовое кольцо |
| spiral | две спиральные руки, сходящиеся к центру |

## zoneStyle — граница и наполнение зоны

| стиль | вид | когда хорош |
|---|---|---|
| default | вращающаяся граница + столбы + туман | универсальный |
| dome | мерцающая полусфера + кольцо основания | барьеры, святилища |
| rune_circle | двойное кольцо + 8 спиц + пульс центра | ритуальные зоны, ловушки |
| vortex | восходящая воронка, сужающаяся кверху | торнадо, огонь-вихрь |
| wall | цилиндр-занавес из поднимающихся частиц | тюрьмы, стены пламени |

## beamStyle — тело луча

| стиль | вид | когда хорош |
|---|---|---|
| default | плотное ядро + оболочка + бегущий импульс | универсальный |
| lightning | мерцающая ломаная с искрами | разряды, ложная тьма |
| spiral | две нити, обвивающие ось | вода, чакра-луч |
| pulse | тонкое ядро + плотные бегущие сгустки | концентрированная энергия |

## Новые эмиттеры-примитивы (Fx.java, public)

Доступны из `/shinobicore fx` и готовых систем; будущие пакеты (боссы,
алтари, святилища, данжи) вызывают их напрямую:

| метод | примитив | типичное применение |
|---|---|---|
| lightPillar(pos, h, tick) | столп света | алтари, воскрешение, босс-фазы |
| vortex(pos, r, h, tick) | торнадо-воронка | ветряные зоны, призыв бури |
| helixColumn(pos, h, r, tick) | двойная восходящая спираль | лечение, баффы, пробуждение |
| shockwaveRing(pos, R, age, dur) | расширяющееся кольцо (каждый тик) | удары боссов, взрывы, парирование |
| chainArc(from, to, tick) | зубчатая дуга между точками | цепная молния, связки печатей |
| groundRunes(pos, r, tick) | трёхкольцевой рунный круг | ритуалы, святилища, гендзюцу |
| domeShell(pos, r, tick) | мерцающий купол | щиты, барьеры деревни |

Все принимают `ElementType` + `VisualDefinition` — цвет/частицы/свечение
техники применяются автоматически.

## Правила совместимости

- Техники без новых ключей ведут себя ровно как в ToolsPack 1.
- Неизвестная строка стиля = default (движок не падает, лог не спамит).
- Studio валидирует стили по этому каталогу (FX Lab → дропдауны).
